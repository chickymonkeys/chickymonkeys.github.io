# AGENTS.md

Nuxt 4 academic website for Alessandro Pizzigolotto, deployed as a static GitHub Pages site.

## Essentials

- Package manager: Bun. Install dependencies with `bun install`.
- Build: `bun run build` (sets `NITRO_PRESET=github_pages`).
- Check changes with `bun run lint` and `bun run fmt:check`.
